# Wiii support

Choose the channel that matches the outcome you need.

| Need | Channel |
| --- | --- |
| Setup or architecture question | Start with [README.md](README.md) and [docs](docs/README.md) |
| Reproducible defect | [Bug report](https://github.com/meiiie/wiii/issues/new?template=bug_report.yml) |
| Product capability | [Feature request](https://github.com/meiiie/wiii/issues/new?template=feature_request.yml) |
| ACP/MCP/host/external adapter | [Integration request](https://github.com/meiiie/wiii/issues/new?template=integration_request.yml) |
| CI, release, docs, or repository maintenance | [Operations task](https://github.com/meiiie/wiii/issues/new?template=operations_task.yml) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); never file publicly |
| Conduct concern | Contact `conduct@wiii.lab` privately |

Before filing an issue:

1. Search open and closed issues.
2. Reproduce on the current supported release or `main`.
3. Include the Wiii version/commit, operating system, surface (desktop/web/API),
   runtime/provider, exact steps, expected result, and actual result.
4. Attach sanitized logs, request IDs, session IDs, screenshots, or recordings.
5. Remove API keys, tokens, private prompts/documents, tenant data, connection
   references, and approval credentials.

For general project contact, use `meokhp888@gmail.com`. The public issue tracker
is reserved for actionable engineering work; do not use it for private account
data or security reports.
