# Research: Release and Desktop Trust Hardening

Date: 2026-08-23

## Verified repository state

- GitHub detects the repository as AGPL-3.0 and already shows the durable AI
  workbench description.
- `wiii-desktop/src-tauri/tauri.conf.json` still declares bundle license `MIT`.
- README's dynamic license badge has stale alt text `MIT license`.
- No public `wiii-v1.2.0` tag or GitHub Release exists.
- The protected stable workflow requires Windows signing secrets, and no release
  environment secrets are currently configured.
- CSP is `null`.
- The only capability targets both `main` and `splashscreen` and grants store,
  dialog, shell, notification, and HTTP access including `https://**`.
- `build.rs` does not declare application commands, leaving them outside the
  per-window ACL generated by Tauri.

## Primary-source findings

- Tauri states that CSP protection is active only when configured and recommends
  the narrowest policy restricted to trusted hosts:
  <https://v2.tauri.app/security/csp/>.
- Tauri capabilities grant permissions to named windows/webviews and are meant
  to reduce the impact of a compromised frontend:
  <https://v2.tauri.app/security/capabilities/>.
- Tauri documents that application commands should be declared through
  `AppManifest::commands` when they need capability control.
- The HTTP plugin's default permission enables fetch operations but requires an
  explicit URL scope: <https://v2.tauri.app/plugin/http-client/>.

## Wiii-specific constraints discovered in code

- Main-window service traffic uses the Tauri HTTP plugin where available; auth
  refresh, login probes, SSE, and WebSocket flows also have browser-native paths.
- Wiii permits a user-configured service endpoint, so a fixed production-only
  origin would break a supported workflow.
- Local development recognizes loopback ports 8000, 8001, and 8080; a bounded
  loopback wildcard remains preferable to a global remote wildcard.
- The app loads Google Fonts and Google favicon images. Pyodide and generated
  visual frames use blob workers/iframes; visual-frame documents already apply
  their own sanitizer and CSP.
- The splash page needs one operation: invoke `close_splash` after its local
  animation. It does not require general window, store, dialog, shell,
  notification, network, file, or process permissions.

## Decision

Proceed with least privilege without pretending Wiii has a fixed cloud origin:
retain explicit loopback and official Wiii origins for the Tauri HTTP plugin,
route arbitrary user-configured remote service endpoints through the existing
browser fetch path subject to CORS, and expose compatibility failures clearly.
This removes blanket native-network authority while preserving local-first and
hosted-web operation.
